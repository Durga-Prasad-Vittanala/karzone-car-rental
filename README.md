# KARZONE – Car Rental Web Application

KARZONE is a responsive car rental web application built using React.js. It provides a simple and user-friendly interface for exploring cars, viewing car details, and submitting booking information.

## Features

- Responsive home page
- Browse available cars
- View individual car details
- Car image gallery
- Booking form with pickup and return dates
- Automatic booking price calculation
- Login and signup interfaces
- Contact page
- Responsive navigation bar

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- React Router DOM
- React Icons
- React Toastify
- Vite

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/Durga-Prasad-Vittanala/karzone-car-rental.git
   ```

2. Navigate to the project folder:

   ```bash
   cd karzone-car-rental
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## Available Scripts
